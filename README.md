## 01 / MISSION

**把 AI 原生的想法，做成可以使用、验证和持续改进的工具。**

我关注企业管理、组织转型与 Agent 实践的交叉点，正在围绕 **DeepSeek Harness** 构建插件：连接业务数据、审查内容质量、沉淀学习成果，以及管理模型与工具的连接。

`AI-native organizations` · `Agentic workflows` · `Context engineering`
